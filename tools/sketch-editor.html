Sketch Editor

Click to place points — they connect in order, with corners rounded automatically. The first point you place becomes the top entry, the last becomes the bottom exit (both required so works can connect into one line, see README.md). Drag a point to move it, double-click a point to delete it. Load a reference photo to trace over it. When you're happy, copy the generated sketch: {...} block into a work in data/works.js.

Tip: aim for roughly the same overall height as the existing sketches (they fill most of the 400×400 box). Keep the shape as ONE continuous route — don't lift the pen; if you need an interior detail (like a handle or a slat), route the click path out to it and back rather than starting a new shape.
